CHECKPOINTED · BOTH REVIEW EVERY GATE
Impact metrics feed back into the next spec: are we meeting them, and where are the bottlenecks?

Where humans stay in the loop

  • Decide the acceptance criteria and the feedback to track
  • Check metrics are met and find the bottlenecks
  • The PM is still the arbiter of what ships

Right-size the spec

  • Simple, well-understood work: a ticket. Issue-as-spec to the coding agent
  • Bigger or ambiguous items: full spec flow that makes decisions and expectations explicit
  • Instruction files (AGENTS.md, copilot-instructions.md) are standing specs

The new engineering job

  • Developers build the agents that build the software
  • Target state: no human writes or reviews code
  • Skip elegance at first: start with a crude agent that reaches the goal, then optimize

    Capturing one aspect of collaboration, dwell is the delta between when one dev creates a pull request (PR) and another acts on it.

    The amount of uninterrupted time a dev has for deep thinking and creative problem solving.

Leadership owns

Small, full-stack teams

  • 10–12 people, cross-functional, owning features end to end
  • Charters that last 12–18 months
  • A rotating customer crew absorbs interrupt-driven work

The bug cap

  • Open bugs ≤ 5 × engineers on the team
  • Over the cap, feature work stops until it's back under
  • Live-site health comes before throughput

Nested OKRs, visible roll-up

  • OKRs cascade with leading indicators
  • Leaders see roll-ups in Delivery Plans or GitHub Projects
  • Visibility without dictating how teams execute
